## A. 引导与配置（对应 D2-01 / D2-03 / D2-04 / D9-01）

- [ ] **A1 首次引导**：全新安装（`simctl uninstall` 后重装）→ 出现「本机 / 远程」选择；选「本机」进入安装引导。**期望**：无 Android 专属权限（存储/电池/无障碍）；不崩溃。记录：截图 + 权限弹窗序列。
- [ ] **A2 引导不被重复**：完成引导后杀 App 重开 → 直接进主界面；设置里能重新进入引导/切换运行位置。**期望**：不重复引导、已有数据不丢。
- [ ] **A3 添加自定义渠道**：设置 › 模型 › 添加渠道 → 兼容协议 OpenAI → Base URL 填 `http://127.0.0.1:3901/v1` → API Key `sk-mock-phase1-model` → 获取模型（mock 返回 `mock-phase1-model`）→ 保存。**期望**：保存成功、模型出现在选择列表。记录：mock 服务请求日志。
- [ ] **A4 模型切换**：对话顶栏模型胶囊 → 选 mock 模型 → 发消息；检查 mock 请求日志的 `model` 字段。**期望**：下一条消息使用新模型。
- [ ] **A5 隐私开关**：设置 › 隐私与分享 → 关闭匿名统计 → 杀 App 重开。**期望**：开关保持关闭；隐私页说明可读；无网络上报（iOS 分支本身不上报，记录说明）。

## B. 引擎（对应 D1-01 / D1-02 / D1-04 / PERSIST-01）

- [ ] **B1 引擎安装**：设置 › 本机引擎 → 安装。**期望**：进度可见；安装完成后状态"已安装"。记录：安装耗时（T6 用）。
- [ ] **B2 安装续装**：安装开始时立刻 `simctl terminate` App → 重开 → 再点安装。**期望**：从断点继续并完成，不崩溃、不重复解压。
- [ ] **B3 引擎启动/停止**：点启动 → 等 ready → 点停止（确认）→ 状态回到已安装。**期望**：状态正确；停止中断进行中的一轮（如正在生成）。
- [ ] **B4 停止后再启动（不重开 App）**：停止后点启动 → 新对话可用。**期望**：成功重启，无需重开 App。
- [ ] **B5 自动启动**：设置里关闭「打开 App 时自动启动」→ 杀 App 重开。**期望**：不自动启动；重新打开开关后冷启动自动启动。
- [ ] **B6 启动失败诊断**：临时破坏引擎产物（如重命名 `app/ios/Engine/` 内一个必需文件；记录操作以便恢复）→ 冷启动。**期望**：显示失败原因 + 重试/日志入口；诊断可复制；App 不崩溃。**恢复**：还原文件。
- [ ] **B7 日志页**：引擎运行 → 日志页 → 滚动/复制。**期望**：实时日志；无完整 API Key/Token（如日志含凭据则记 BUG）。

## C. 对话闭环（对应 D3-01…D3-08 / D3-19）

- [ ] **C1 新对话**：主界面新对话 → 不发送。**期望**：空状态输入框可用；抽屉**不新增**空会话。发送首条后会话才出现。
- [ ] **C2 流式**：mock 场景 `stream`（通过请求头/模型名触发，见 `mocks.md`）→ 发送。**期望**：回复分片出现（可看到中间态）；最终完整；重开仍在。
- [ ] **C3 思考折叠**：mock 场景含 thinking → 展开/收起思考块。**期望**：收起显示首行预览；思考不混入正式回答。
- [ ] **C4 插话**：生成中直接发一条消息。**期望**：消息显示在底部；生成不中断；mock 下一条请求包含该消息（查日志）。
- [ ] **C5 排队/撤回**：生成中长按发送 → 排队 → 结束后自动发送；再试「撤回」。**期望**：顺序正确；撤回内容回到输入框。
- [ ] **C6 停止**：生成中点停止。**期望**：本轮停止、UI 回 idle、已生成内容保留；可立即发下一条。
- [ ] **C7 审批允许**：mock 场景 `approval` → 触发工具调用 → 审批卡显示命令/原因 → 允许本次。**期望**：工具执行一次；工具行显示结果。
- [ ] **C8 审批拒绝**：同 C7 → 拒绝。**期望**：工具**不执行**（工作区无文件）；对话继续；工具行显示拒绝。
- [ ] **C9 工具行**：点开工具行。**期望**：参数/结果可见；失败工具显示错误态。
- [ ] **C10 消息操作**：复制 / 长按菜单 / 重新回答（最后一条）/ 引用。**期望**：复制内容正确；重新回答进入新对话且原对话不变；引用块随消息发出。
- [ ] **C11 提问卡**：mock 场景触发提问（若 mock 支持）→ 选项提交。**期望**：卡片变已答，结果回传（无 mock 支持时标 `DEFERRED-MOCK` 并记录原因）。

## E. 持久化与恢复（对应 PERSIST-01）

- [ ] **E1 杀 App 重开**：完成一轮（含工具调用）→ `simctl terminate` → 重开。**期望**：会话/消息完整；可继续对话；引擎自动重启。
- [ ] **E2 引擎重启恢复**：停止引擎 → 启动 → 打开原会话。**期望**：消息完整、继续正常。
- [ ] **E3 结果未知**：mock 场景 `unknown_inflight`（或工具执行中杀 App）→ 重开该会话。**期望**：横幅提示；确认前工具被拒绝；确认后对话继续且不重跑工具。
- [ ] **E4 草稿恢复**：输入草稿 + 添加附件未发送 → 杀 App → 重开。**期望**：按 D4-07 约定恢复或明确提示（记录实际行为）。

## F. 远程主机（对应 D1-09 / D1-10 / D1-11）

> 无真实 SSH/Remote 服务器时，使用 fake host/transport（L4）并在此标注 `DEFERRED-LIVE`；不要伪造真连结果。

- [ ] **F1 主机切换**：抽屉底部 → 切换主机 → 本机/远程。**期望**：当前主机名/状态可见；会话跟随切换。
- [ ] **F2 连接失败回退**：添加一个不可达 SSH 主机 → 连接。**期望**：错误可读、可重试；可切回本机。
- [ ] **F3 SSH 连接（可选，需本机 sshd）**：按 `guide/zh/03-engine-hosts.md` 步骤添加 SSH 主机 → 测试连接 → 信任指纹 → 保存 → 连接。**期望**：远端会话列表加载、发消息流式。记录：host/端口/是否真实 host。
- [ ] **F4 断线重连**：连接后断开网络（`simctl` 或关掉 sshd）→ 恢复。**期望**：自动重连、消息不重复。
- [ ] **F5 DSH Remote（可选）**：无真实服务器则标 `DEFERRED-LIVE`；用 fake transport 验证连接/会话/重连（L4 已自动覆盖）。
